# Backend Development with Node.js & Express

This repository contains multiple backend-focused projects and experiments built using Node.js and Express.js. It covers core backend concepts such as REST APIs, MVC architecture, file handling, asynchronous operations, and database-driven applications.

The repository is structured as a collection of independent modules and mini-projects, each focused on a specific backend concept or use case.

---

## 📂 Project Structure

├── 02urlShortner/
│ └── URL Shortener backend using Express
│
├── 03vottingApp/
│ └── Voting Application backend (complete version)
│
├── BlockingOrNonBlocking/
│ └── Demonstrates blocking vs non-blocking operations in Node.js
│
├── SERVER/
│ └── Express server setup and routing basics
│
├── helloworld/
│ └── File handling using Node.js fs module
│
├── MOCK_DATA.json
│ └── Sample data for API testing
│
├── log.txt
│ └── Logging output
│
├── package.json
├── package-lock.json
└── node_modules/

## 🚀 Key Concepts Covered

- Node.js runtime fundamentals
- Express.js server setup and routing
- RESTful API development
- MVC (Model-View-Controller) architecture
- Blocking vs Non-Blocking operations
- File system operations using `fs`
- JSON-based data handling
- API status codes and error handling
